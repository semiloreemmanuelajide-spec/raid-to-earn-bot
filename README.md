# ⚡ Netwise Multi-Chain Raid-to-Earn Telegram Bot (SaaS)

An automated, commercial-grade Raid-to-Earn utility built for Web3 communities across **Solana, Base, TON, Ethereum, and EVM chains**. It verifies X (Twitter) engagement via Twitter API v2, eliminates fake proof claims, and aggregates verified multi-chain wallets for automated bulk payouts.

---

## 🔥 Features
- 🌐 **Multi-Chain Wallet Architecture:** Onboard raiders once with support for Solana, EVM (Base/ETH/BSC), TON, and Bitcoin addresses.
- 🔒 **SaaS Subscription Licensing:** Group whitelisting via managed expiration dates (`AllowedGroups`).
- 🤖 **Global User Onboarding:** Direct message `/register` binds a Telegram ID to Twitter handles and multi-chain wallet destinations.
- 🎯 **API Proof-of-Work Verification:** Queries Twitter API v2 to verify real likes/retweets before approving entries.
- ⏱️ **Automated Cron Engine:** Auto-expires raids and posts chain-specific verified wallet export lists for instant batch execution.
- 🏆 **Speed & Performance Leaderboards:** Identifies and ranks top-performing raiders by execution speed.

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express, `node-telegram-bot-api`
- **Database:** MySQL, Sequelize ORM
- **APIs:** Twitter API v2 (`twitter-api-v2`), `node-cron`
- **Deployment:** Render, Aiven Cloud MySQL, UptimeRobot
